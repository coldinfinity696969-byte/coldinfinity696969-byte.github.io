# Никита Ульянов — портфолио

Одностраничный сайт-портфолио AI-специалиста (маркетинг · дизайн · видео · сайты).

## Что внутри
- `index.html` — разметка, стили и основные скрипты сайта.
- `assets/flow.js` — связки между разделами: заголовки по словам, раскрытие блока услуг кругом, провод из услуг в проекты, линия процесса по прокрутке.
- `assets/svc/pipeline.js` — живые сцены и провода в блоке услуг.
- `assets/reel/` — шоурил сайтов на Three.js и текстуры экранов.
- `assets/portfolio/` — картинки и видео кейсов.
- `promo/` — вариант страницы с плавным скроллом. Собирается из `index.html`: после правок главной запусти `python promo/build.py`.

## Технологии
- Чистый HTML/CSS/JS, без сборки.
- [GSAP](https://gsap.com/) + ScrollTrigger — появление блоков.
- [Three.js](https://threejs.org/) — шоурил.
- [Lenis](https://lenis.darkroom.engineering/) — плавный скролл, только в `/promo/`.
- Шрифты: Unbounded, Onest, JetBrains Mono (Google Fonts).

## Как открыть локально
Шоурил грузит модули и текстуры, поэтому нужен локальный сервер:
```
python -m http.server
```
и открыть http://localhost:8000.

## Публикация
Сайт хостится на GitHub Pages. После изменений:
```
git add .
git commit -m "описание правки"
git push
```
Через ~1 минуту обновление появляется на сайте.
