# Никита Ульянов — портфолио

Одностраничный сайт-портфолио AI-специалиста (маркетинг · дизайн · видео · сайты).

## Что внутри
- `index.html` — весь сайт в одном файле (HTML + CSS + JS, картинки встроены).
- `assets/` — фавиконка и изображения для соцсетей.

## Технологии
- Чистый HTML/CSS/JS — без сборки, открывается двойным кликом.
- [GSAP](https://gsap.com/) + ScrollTrigger — анимации.
- [Lenis](https://lenis.darkroom.engineering/) — плавный скролл.
- Шрифты: Unbounded, Onest, JetBrains Mono (Google Fonts).

## Как открыть локально
Просто открой `index.html` двойным кликом в браузере.

## Публикация
Сайт хостится на GitHub Pages. После изменений:
```
git add .
git commit -m "описание правки"
git push
```
Через ~1 минуту обновление появляется на сайте.
